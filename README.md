# 🍿POPFLIX🍿
---
## 📝 Informacion general 
Somos un equipo de pseudo-desarrolladores aprendiendo herramientas basicas de front-end. La encomienda de esta actividad es usar una API (de elección libre) para reforzar lo aprendido en clase. 

De esta manera llegamos a la API "The movieDB" con la que se pueda desarrollar una página web de recomendación de películas y series. La plataforma  ofrece  base de datos completa con fichas técnicas y artísticas de películas, documentales, cortometrajes, y series de televisión.

---
## Características Actuales

✅ Presentación final basada en el prototipo de Figma.
✅ Implementación de la API de TMDB para mostrar películas populares.
✅ Visualización dinámica por género.
✅ Modal con detalles completos de cada película (sinopsis, año, idioma, géneros y tráiler).
✅ Diseño completamente responsive y estilizado con Bootstrap y CSS.

## Instalación
Es necesario tener una cuanta en TheMovieDB y una API key (v3). Posterior a esto, para la instalación se tienen que seguir los siguientes pasos:

1. Clona el repositorio:
```Bash
git clone https://github.com/Vhinil-O/Reto_02_Pelicula
```

2. Navega al directorio del proyecto:
```Bash
cd nombre-local-de-tu-proyecto
```

3. Crea el archivo `config.js` y define tu API Key:
```js
const CONFIG = {
  API_KEY: "TU_API_KEY_AQUI"
};
```

4. Abre `index.html` en tu navegador.
